# Investplay

Investigating Interface Design Effects on Human Reliance Calibration

---

## Overview
This project examines whether a novel contrastive-interrogative explanation interface can simultaneously reduce both over-reliance and under-reliance on AI recommendations — a problem termed dual calibration.
Most prior work on AI-assisted decision-making addresses either over-reliance or under-reliance, rarely both. This study directly extends Ma et al. (2024), who identified dual calibration as an open problem and called for future research.
The experimental context is a simulated financial fraud/distress detection task, where participants assess fictional company health before and after receiving AI feedback under one of three interface conditions.
